## Разработка системы распознавания голосовых команд (Voice Assistant Lite)

### 1. ключевая цель
Программа, которая распознаёт голосовые команды с микрофона и выполняет действия на компьютере (аналог простого голосового помощника).

---

### 2. Технологии

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3 |
| Интерфейс | Tkinter |
| Запись с микрофона | `sounddevice` / `pyaudio` |
| Распознавание речи | `vosk` (офлайн, работает без интернета) |
| Выполнение действий | `pyautogui`, `os`, `subprocess` |
| Сборка | PyInstaller (.exe) |

**Почему Vosk:** работает полностью офлайн, не требует отправки данных в интернет, бесплатно, русский язык поддерживается.

---

### 3. Функциональные требования

#### 3.1. Основные функции

| Функция | Описание |
|---------|----------|
| Запуск/остановка прослушивания | Кнопки "Слушать" и "Стоп" |
| Распознавание команд | Преобразование голоса в текст |
| Выполнение команд | Анализ текста и выполнение действия |
| Голосовой ответ | Программа говорит "Выполнено" / "Команда не распознана" |
| Журнал команд | Список последних распознанных команд и результатов |

#### 3.2. Поддерживаемые команды (минимум 10)

| Категория | Команда | Действие |
|-----------|---------|----------|
| **Система** | "открой калькулятор" | Запускает calc.exe |
| | "открой блокнот" | Запускает notepad.exe |
| | "закрой окно" | Alt+F4 |
| | "выключи компьютер" | shutdown /s /t 10 (с подтверждением) |
| **Интернет** | "открой почту" | Открывает mail.ru / gmail в браузере |
| | "что нового" | Открывает новостной сайт |
| **Управление ПК** | "заблокировать экран" | Win+L |
| | "увеличь громкость" | Увеличивает громкость системы |
| | "уменьши громкость" | Уменьшает громкость |
| | "какое сегодня число" | Говорит текущую дату |
| | "сколько времени" | Говорит текущее время |
| **Пользовательские** | "выполни команду ..." | Выполняет любую консольную команду |

#### 3.3. Интерфейс (простой)

```
┌─────────────────────────────────────────────────────────────┐
│                    ГОЛОСОВОЙ ПОМОЩНИК                       │
│                                                             │
│                    🎤 [СЛУШАТЬ] [СТОП]                      │
│                                                             │
│      Статус: Ожидание команды...                            │
│                                                             │
│      ┌─────────────────────────────────────────────────────┐
│      │ ЖУРНАЛ КОМАНД                                       │
│      ├─────────────────────────────────────────────────────┤
│      │ 12:30:15 → "открой калькулятор" → ✅ выполнено      │
│      │ 12:31:22 → "сколько времени" → ✅ 12:31:22          │
│      │ 12:32:05 → "чего" → ❌ не распознано                │
│      └─────────────────────────────────────────────────────┘
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.4. Добавление новых команд

- Возможность добавлять свои команды через конфигурационный файл `commands.json`
- Формат: `{"фраза": "действие"}`

---

### 4. Архитектура

```
[Микрофон] → [sounddevice] → [Vosk распознавание] → [текст команды]
                                                         ↓
                                                  [Анализ команды]
                                                         ↓
┌────────────────────────────────────────────────────────────┐
│  pyautogui    │    subprocess    │    datetime    │   os   │
│  (клавиши)    │  (запуск команд)  │  (дата/время)  │ (громкость)│
└────────────────────────────────────────────────────────────┘
```
