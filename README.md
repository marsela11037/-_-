# Проект «Голосовой ассистент "Джо"»


## Описание предметной области и функциональности

Разработка офлайн-голосового ассистента для управления компьютером с помощью голосовых команд. Ассистент работает полностью без доступа к интернету, что гарантирует конфиденциальность голосовых данных пользователя. Пользователь активирует ассистента по имени «Джо» (поддерживается 7 вариантов произношения), после чего может отдавать голосовые команды.

**Ключевые функциональные сценарии (Use Cases):**

- **Активация ассистента:** Пользователь произносит имя «Джо». Ассистент отвечает случайной фразой («Да», «Слушаю», «На связи») и переходит в режим прослушивания команд.

- **Непрерывное выполнение команд:** Можно говорить «Джо включи ютуб» — команда выполняется сразу, без ожидания подтверждения.

- **Запуск приложений:** По команде запускаются калькулятор, блокнот, Discord и другие программы.

- **Открытие сайтов:** Команды открывают YouTube, почту, новости, SoundCloud в браузере.

- **Управление системой:** Регулировка громкости, блокировка экрана, закрытие активного окна (Alt+F4).

- **Безопасные опасные команды:** Выключение компьютера требует голосового подтверждения «да» или «нет».

- **Пользовательские команды:** Возможность добавлять свои команды через интерфейс или файл `commands.json`.

- **Фоновая работа:** Ассистент сворачивается в системный трей, продолжает слушать команды и не мешает работе.

## Технологический стек и инструментарий

| Категория | Конкретные инструменты и технологии |
|:---|:---|
| **Язык программирования** | Python 3.10+ |
| **Распознавание речи** | Vosk (офлайн-модель для русского языка) |
| **Синтез речи (основной)** | Piper TTS (нейросетевой, голос Denis) |
| **Синтез речи (резервный)** | pyttsx3 (Microsoft Irina) |
| **Графический интерфейс** | Tkinter (нативное окно) |
| **Работа с микрофоном** | sounddevice + NumPy |
| **Управление системой** | pyautogui, subprocess, win32com |
| **Иконка в трее** | pystray + Pillow |
| **Сборка .exe** | PyInstaller |
| **Конфигурация** | JSON-файлы (config.json, commands.json) |
