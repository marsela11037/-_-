# 🎙 Voice Assistant Lite

Голосовой ассистент на Python + Vosk (офлайн) для управления компьютером голосом.

---

## Требования

- Python 3.10+
- Windows 10/11
- Микрофон

---

## Установка

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Скачать модель Vosk (русский язык)

Перейдите на https://alphacephei.com/vosk/models и скачайте одну из моделей:

| Модель | Размер | Качество |
|--------|--------|----------|
| `vosk-model-small-ru-0.22` | ~45 МБ | Быстрая, для слабых ПК |
| `vosk-model-ru-0.42` | ~1.8 ГБ | Высокое качество |

**Рекомендуется для начала:** `vosk-model-small-ru-0.22`

После скачивания распакуйте архив и переименуйте папку в `model`:

```
voice_assistant/
├── model/          ← папка с моделью (переименовать!)
│   ├── am/
│   ├── conf/
│   └── ...
├── voice_assistant.py
├── commands.json
└── requirements.txt
```

### 3. Запустить

```bash
python voice_assistant.py
```

## Поддерживаемые команды

| Команда | Действие |
|---------|----------|
| «открой калькулятор» | Запускает calc.exe |
| «открой блокнот» | Запускает notepad.exe |
| «закрой окно» | Alt+F4 |
| «выключи компьютер» | shutdown /s /t 10 (с подтверждением) |
| «открой почту» | Открывает mail.ru в браузере |
| «что нового» | Открывает новости Яндекс |
| «заблокировать экран» | Win+L |
| «увеличь громкость» | +5 делений громкости |
| «уменьши громкость» | −5 делений громкости |
| «какое сегодня число» | Произносит текущую дату |
| «сколько времени» | Произносит текущее время |
| «выполни команду <cmd>» | Выполняет консольную команду |

## Добавление своих команд

### Через интерфейс
Нажмите кнопку **➕ Добавить команду**, введите фразу и действие.

### Вручную через commands.json
```json
{
  "открой браузер": "cmd:start chrome",
  "открой проводник": "cmd:explorer",
  "мой сайт": "https://example.com"
}
```

Форматы действий:
- `notepad.exe` — запустить программу
- `https://...` — открыть URL в браузере
- `cmd:ipconfig` — выполнить консольную команду

## Сборка .exe

```bash
pip install pyinstaller
pyinstaller build.spec
```

Готовый файл появится в папке `dist/VoiceAssistant.exe`.

> ⚠ Перед сборкой убедитесь, что папка `model/` находится рядом с `voice_assistant.py`.

---

## Безопасность

- Vosk работает **полностью офлайн** — голос не передаётся в интернет
- Опасные команды (выключение ПК) требуют **голосового подтверждения** («да» / «нет»)
- Список запрещённых команд: `format c:`, `del /f /s /q c:\`, `rm -rf /`
