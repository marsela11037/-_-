# Голосовой помощник «Лав» — оффлайн-ассистент с активацией по имени

📚 Документация и исходный код проекта: см. репозиторий проекта.

## Описание предметной области и функциональности

Разработка десктопного голосового помощника для Windows с активацией по имени **«Лав»**. Программа постоянно слушает микрофон в фоновом режиме, распознаёт речь полностью офлайн (без передачи данных в интернет) с помощью движка Vosk и реагирует на голосовые команды: запускает приложения и сайты, управляет звуком, блокирует экран, отвечает на вопросы голосом, ведёт журнал команд. Пользователь может добавлять собственные команды через диалог в интерфейсе или напрямую в `commands.json`.

Ключевая техническая особенность — **полностью офлайн распознавание речи** через локальную модель Vosk и активация по ключевому слову (wake-word). После произнесения «Лав» открывается короткая «сессия команд», в течение которой можно отдавать команды без повторного обращения по имени. Голосовые ответы синтезируются через Windows SAPI (`Microsoft Irina`) с фолбэком на pyttsx3 и опциональной поддержкой Piper TTS для более качественного синтеза.

## Ключевые функциональные сценарии (Use Cases)

1. **Активация и распознавание команды.** Программа постоянно слушает микрофон через `sounddevice.RawInputStream`. При обнаружении wake-word «Лав» (с дебаунсом и таймаутом сессии) ассистент отвечает короткой репликой («Слушаю», «Я тут») и принимает следующую фразу как команду. В течение сессии (по умолчанию 8 секунд) последующие команды можно отдавать без имени.
2. **Выполнение команды.** Распознанный текст ищется в словаре встроенных команд (с большим количеством синонимов: «открой ютуб» / «включи ютуб» / «ютуб открой»). При совпадении выполняется действие соответствующего типа: запуск приложения через `subprocess`, открытие URL через `webbrowser`, нажатие сочетания клавиш через `pyautogui`, изменение громкости, получение даты/времени и т.д.
3. **Голосовой ответ.** На каждое выполненное действие ассистент отвечает голосом с использованием Windows SAPI (`SAPI.SpVoice` через `win32com.client`). Модуль `voice_replies.py` подбирает случайную фразу из набора вариантов, что даёт «живой» характер общения. На маты программа реагирует обиженно, на пасхалки про Джо Голдберга («Hello you», «ты Лав Куин?») — соответствующими репликами.
4. **Подтверждение опасных действий.** Команды вроде «выключи компьютер», «перезагрузи» помечены как `danger`. Перед выполнением ассистент переспрашивает «Точно? Скажи да или нет», и только после голосового подтверждения «да» выполняет команду.
5. **Управление окном программы.** Голосовые команды «спрячься», «в трей», «сверни» убирают окно в системный трей (через `pystray`). Команды «разверни», «покажись», «вылези из трея» возвращают его на экран. Также голосом можно вызвать окно списка команд («покажи команды») и окно создания пользовательской команды («как создать команду»).
6. **Добавление пользовательских команд.** Через окно создания команды или редактируя `commands.json`, пользователь связывает произвольную фразу с действием: путь к программе (`notepad.exe`), URL (`https://example.com`) или системная команда (`cmd:ipconfig`). Запрещённые команды (форматирование диска, рекурсивное удаление) блокируются на уровне `FORBIDDEN_COMMANDS`.
7. **Ведение журнала.** Все распознанные команды и их результаты пишутся в журнал в интерфейсе с временной меткой, цветовой подсветкой (успех/ошибка/wake-word/info) и сохраняются в текущей сессии для просмотра.

## Технологический стек и инструментарий

| Категория | Конкретные инструменты и технологии |
|-----------|-------------------------------------|
| Язык | Python 3.10+ |
| Графический интерфейс | Tkinter (стандартная библиотека); кастомные «стеклянные» кнопки на `tk.Canvas` с градиентом, бликом и hover-эффектами |
| Запись звука | `sounddevice` (PortAudio): `RawInputStream` с частотой 16 кГц, моно, 16-bit |
| Распознавание речи | **Vosk** (офлайн): `Model` + `KaldiRecognizer`; модель `vosk-model-small-ru-0.22` (~45 МБ) |
| Wake-word | Собственная реализация поверх частичных результатов Vosk (`PartialResult`) — без внешних библиотек, с дебаунсом и таймаутом сессии |
| Синтез речи (TTS) | Windows SAPI через `win32com.client` (голос `Microsoft Irina`); фолбэк на `pyttsx3`; опционально `piper-tts` для качественного нейросетевого синтеза |
| Системные действия | `subprocess` (запуск приложений), `pyautogui` (горячие клавиши, громкость, скриншот), `webbrowser` (URL и Steam-протокол `steam://rungameid/...`) |
| Системный трей | `pystray` + `Pillow` для иконки |
| Конфигурация | JSON-файлы: `config.json` (настройки), `commands.json` (пользовательские команды), `piper_config.txt` (выбранный голос Piper) |
| Сборка дистрибутива | **PyInstaller** в режиме `--onefile --windowed`; ресурсы (модель Vosk, библиотеки, иконка) встраиваются внутрь исполняемого файла |
| Тестирование | Набор скриптов `test_*.py` для проверки TTS, распознавания и GUI-звука |

## Инструкция по развёртыванию и запуску проекта

### Системные требования

| Компонент | Требование |
|-----------|-----------|
| Операционная система | Windows 10 или Windows 11 (только Windows: используется SAPI и `pywin32`) |
| Python | версия 3.10–3.13 (для разработки) |
| Память (RAM) | минимум 512 МБ |
| Дисковое пространство | минимум 200 МБ (включая модель Vosk) |
| Дополнительно | микрофон; Git (для клонирования репозитория) |

### Запуск из исходников

**1. Клонирование репозитория**

```bash
git clone <url-репозитория>
cd vois
```

**2. Создание виртуального окружения (Windows)**

```cmd
python -m venv venv
venv\Scripts\activate
```

**3. Установка зависимостей**

```bash
pip install -r requirements.txt
```

**4. Загрузка модели Vosk**

Скачайте модель `vosk-model-small-ru-0.22` с https://alphacephei.com/vosk/models, распакуйте архив и переименуйте папку в `model/`. Структура: `model/am/`, `model/conf/`, `model/graph/`, `model/ivector/`.

**5. Запуск приложения**

```bash
python voice_assistant.py
```

После запуска появится главное окно. Программа автоматически начнёт слушать микрофон.

### Запуск через готовый .exe

Файл `dist/Лав.exe` (~102 МБ) — самодостаточный дистрибутив, в который упакованы Python-рантайм, все библиотеки и офлайн-модель Vosk. Скопируйте файл на любой ПК с Windows 10/11 и запустите двойным кликом — установка не требуется.

### Сборка собственного .exe

```cmd
pyinstaller --onefile --windowed --noconfirm --clean ^
  --name "Лав" --icon "icon.ico" ^
  --add-data "model;model" ^
  --add-data "commands.json;." ^
  --add-data "config.json;." ^
  --add-data "voice_replies.py;." ^
  --add-data "builtin_commands.py;." ^
  --add-data "icon.ico;." ^
  --add-binary "<path-to>\vosk\libvosk.dll;vosk" ^
  --add-binary "<path-to>\vosk\libstdc++-6.dll;vosk" ^
  --add-binary "<path-to>\vosk\libgcc_s_seh-1.dll;vosk" ^
  --add-binary "<path-to>\vosk\libwinpthread-1.dll;vosk" ^
  --hidden-import=win32com --hidden-import=win32com.client ^
  --hidden-import=pythoncom ^
  --hidden-import=pystray --hidden-import=PIL ^
  --exclude-module=PyQt5 ^
  voice_assistant.py
```

В коде используется хелпер `resource_path()`, корректно находящий ресурсы как при запуске исходников, так и из распакованного `sys._MEIPASS` внутри .exe.

## Быстрый старт после запуска

1. Запустите `python voice_assistant.py` (или `dist/Лав.exe`).
2. В появившемся окне нажмите кнопку **▶ слушать** (если автозапуск выключен) — программа начнёт слушать микрофон.
3. Произнесите имя ассистента: **«Лав»**. Она ответит коротким подтверждением.
4. В течение 8 секунд скажите команду, например:
   - «Лав, включи ютуб»
   - «Лав, сколько времени»
   - «Лав, открой калькулятор»
   - «Лав, увеличь громкость»
   - «Лав, как создать команду»
5. Чтобы добавить свою команду, нажмите кнопку **+ своя** в интерфейсе или скажите голосом «Лав, как создать команду».
6. Полный список команд — кнопка **?** или голосовая команда «Лав, покажи команды».

## Конфигурация

Файл `config.json` — настройки, изменяемые через интерфейс или вручную:

```json
{
  "voice_enabled": true,
  "voice_volume": 0.44,
  "wake_timeout": 8.0,
  "piper_voice": "denis",
  "close_to_tray": false,
  "ui_theme": "love",
  "ui_animations": true,
  "auto_listen_on_start": false,
  "tts_rate": 220,
  "log_lines": 5,
  "voice_id": "HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft\\Speech\\Voices\\Tokens\\TTS_MS_RU-RU_IRINA_11.0",
  "start_minimized": false
}
```

Файл `commands.json` — пользовательские команды:

```json
{
  "_comment": "Пользовательские команды. Формат: 'фраза': 'действие'",
  "открой браузер": "cmd:start chrome",
  "открой проводник": "cmd:explorer",
  "мой сайт": "https://example.com"
}
```

Поддерживаемые форматы действия:
- путь к исполняемому файлу: `notepad.exe`, `calc.exe`, `discord`
- URL: `https://...` (открывается в браузере по умолчанию)
- консольная команда: `cmd:<команда>` (выполняется через `subprocess.Popen(shell=True)`)

## Безопасность

- **Полностью офлайн**: ни голос, ни распознанный текст никогда не покидают устройство пользователя. Vosk работает локально, голос синтезируется системным SAPI.
- **Чёрный список команд**: `FORBIDDEN_COMMANDS = ["format c:", "del /f /s /q c:\\", "rm -rf /", "rmdir /s /q c:\\"]`. Любая попытка выполнить такую команду блокируется.
- **Подтверждение опасных действий**: выключение/перезагрузка ПК выполняются только после голосового «да».
- **UTF-8 в stdout**: при запуске форсируется `sys.stdout.reconfigure(encoding="utf-8")` — сообщения с эмодзи и кириллицей не падают в Windows-консоли (cp1251).

## Возможные доработки

1. **Кросс-платформенность**: вынести зависимости от Windows (SAPI, `pywin32`) за интерфейс TTS, добавить реализацию через `espeak`/`festival` для Linux и `say` для macOS.
2. **Локальные LLM-ответы**: подключить небольшую офлайн-модель (например, через `llama.cpp`) для свободного диалога вместо набора заранее заготовленных реплик.
3. **Автозапуск с Windows**: добавить кнопку «запускать вместе с системой» (создание ярлыка в `shell:startup` или ключ реестра).
4. **Обучение пользовательскому wake-word**: возможность задать своё имя для активации вместо «Лав».
5. **История команд между сессиями**: сохранение журнала в SQLite для просмотра прошлых сессий.
